# Test bills

Photos of real restaurant bills for trying the scan → split flow (Capture → "Choose from library",
or drag one onto the capture screen on desktop). Mixed formats on purpose — HEIC (iPhone), JPEG,
PNG, WebP and AVIF — to exercise the in-browser conversion. Collected from gdp-mobile/test-fixtures
and the earlier group-dine-pay monorepo's backend fixtures.

Uploading the same photo twice reuses the existing bill (dedup by content hash), so pick a
different one, or re-save/crop it, to get a fresh session.
